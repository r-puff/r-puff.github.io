Personal OBS Studio integration

Rowan Stream Setup

A free, locally operated OBS Studio browser dock for preparing and controlling livestreams on Twitch and YouTube.

About this application

Rowan Stream Setup lets its user save stream presets, edit Twitch and YouTube titles and descriptions, select YouTube playlists and thumbnails, preview changes, and prepare livestreams. With explicit confirmation, it can request OBS Studio and Multiple RTMP to start or stop both streaming outputs.

Why it requests YouTube access

The application uses YouTube API Services to view the authorized account's playlists and broadcast information, and to create or update livestream metadata, thumbnail, playlist assignments, and settings when requested by its user. Google OAuth provides permission for these actions.

The application runs on the user's own computer. This site is informational, not the application's streaming interface. OBS credentials, OAuth tokens, stream keys, and saved stream settings are not published here. This project is intended for personal use, not public account registration.

Privacy and terms

See the Rowan Stream Setup Privacy Policy for details about access, local storage, and how to revoke Google permissions.

Use of the YouTube integration is subject to the YouTube Terms of Service, and Google's own handling of account data is explained in the Google Privacy Policy.
