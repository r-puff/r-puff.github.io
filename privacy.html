Privacy Policy

Effective November 12, 2026

Rowan Stream Setup is a personal, locally operated tool for managing Twitch and YouTube livestream settings through an OBS Studio browser dock. This policy describes how it handles information when a user connects a YouTube account using Google OAuth.

Information accessed

The application uses YouTube API Services to read the authorized account's channel and livestream information needed for its features. This may include broadcast and channel identifiers, broadcast status, titles, descriptions, tags, categories, audience and visibility settings, playlist names and identifiers, schedule information, thumbnail information, and existing stream-to-broadcast assignments.

How it uses the information

This information is used to show and compare stream settings, maintain local drafts and presets, check for conflicting broadcasts, and apply actions requested by the user. Those actions can include creating or updating broadcasts, updating thumbnails and metadata, using or creating playlists, and associating broadcasts with existing streams. Streaming actions require the user's confirmation in the OBS dock.

Storage and sharing

Google OAuth tokens, application configuration, drafts, presets, and certain cached information are stored locally on the user's computer to operate the application. The application communicates with Google's YouTube APIs to read information and carry out approved changes. It does not operate a developer-hosted database, sell YouTube account data, or use that data for advertising.

This informational website is hosted by GitHub Pages and does not require a Google login. GitHub may process site-visitor information under its privacy statement.

Retention, deletion, and revoking access

Locally saved data remains on the user's computer until the user clears the relevant application data. The user can revoke Google authorization at any time through Google Account third-party connections. Revocation prevents future authorized requests; deletion of existing local OAuth credentials and caches is a separate step. To locate those files safely, the user can request assistance through the project contact link below before removing them.

Other policies

Rowan Stream Setup uses YouTube API Services. Use of the YouTube integration is also subject to the YouTube Terms of Service. Google's own practices are covered by the Google Privacy Policy.

Updates and contact

This policy may be updated when the application or its data practices change. Substantive changes will be reflected in the effective date. Questions can be raised through the repository's GitHub Issues page. Never share credentials, tokens, or stream keys in a public issue.
